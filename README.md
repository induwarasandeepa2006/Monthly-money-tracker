# Monthly Money Tracker

A simple, free tool to plan your month and track daily spending. Built by AURA.

**Live site:** https://YOUR-USERNAME.github.io/YOUR-REPO/

## What it does

- **Today:** set a daily spending limit (default Rs 1,500) and see how much is left.
- **Extra fees:** log one-off costs with a note. They come out of your monthly money without using up the daily limit.
- **Month:** enter the money you received and see what is left, day by day.
- **Savings:** every finished day counts what you did not spend of the daily limit.

## Your data stays with you

Everything is saved in your own browser (localStorage). Nothing is sent to a server, and nobody else can see your entries. Data is stored per device, browser and web address, so it does not sync between devices. Clearing your browser data erases it.

## Run it yourself

It is a single file with no build step. Download `index.html` and open it in a browser, or host it on GitHub Pages, Netlify or Cloudflare Pages.
